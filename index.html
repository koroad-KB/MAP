유의사항
• 차량거리는 그룹별 실제 도로 경로 조회를 실행하면 출발지(인천교통정보센터)에서 그룹 장비를 차례로 방문하는 경로의 거리와 예상 운행시간을 표시합니다. 출발지 복귀는 포함하지 않으며 실제 교통·현장 여건에 따라 달라질 수 있습니다.
• 차량거리 기능은 Apps Script 스크립트 속성 KAKAO_MOBILITY_REST_KEY와 카카오모빌리티 길찾기 API 이용 권한 설정이 필요합니다.
• 날씨는 기상청 단기예보를 기준으로 오전 10시~오후 3시 예보를 평가합니다. 그룹 순위는 거리와 무관하며, 기상정보 조회 실패 시 안전으로 간주하지 않습니다.
• 날씨만으로 작업 안전을 확정하지 마세요. 도로 교통상황, 주차·작업공간, 고소작업 기준, 현장 위험성평가를 별도로 확인해야 합니다.
• 점검 상태는 연결된 Google Sheets에 저장되며, 약 15초마다 다른 사용자의 변경 사항을 확인합니다. 네트워크 오류 시 저장 여부를 확인하세요.
